# 还缺的场景图

每个地点要一张 SVG，放 `assets/img/scenes/<文件名>.svg`，规格和值班室、入口那两张一样：`viewBox="0 0 1280 720"`，裁切铺满，重要物件放在中间 90% 范围内，可点物件放在带 id 的分组里（透明点击区域也可以），点击区域最小边至少 40 像素。

id 统一用 `hs-` 加下表里的“热点 id”。接入时我会在场景数据里加上 `"scene": "<文件名>"`。可选的 `flicker`（灯光闪烁）和 `states`（解谜后显示的图层，如开门）我来配。

已有：北侧应急入口（`prologue-entrance`）、值班室（`ch1-duty`）。
