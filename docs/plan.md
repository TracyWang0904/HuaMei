## 已定下的决定

| 决定 | 说明 |
|---|---|
| 技术栈 | Vite + 原生 JavaScript，不引入框架 |
| 受众 | 只给三五个人分享，不上 itch.io 的完整发布流程；以后要给更多人玩，改托管即可，代码不用动 |
| 平台 | 只面向电脑浏览器，不做手机适配 |
| 存档 | 只通过 `src/core/storage.js`，内部是 localStorage；设置里可导出/导入存档文本 |
| 答案 | 只存加盐 SHA-256，源码里没有明文。每个输入框的哈希 id 是 `谜题id.字段key`，用 `npm run hash -- <id> <答案>` 生成 |
| 沉浸式 | 场景 SVG 铺满整个窗口（裁切模式）；地图、笔记本、设置只是右上角的小按钮；画面上不放文字提示 |
| 窗口风格 | 所有弹窗和电脑屏幕都是千禧年 Windows 95/98 风格，窗口小而可拖动，不覆盖整个页面。配色取自提供的矢量素材：窗体 #c0c0c0、标题栏 #2c2cb9 |
| 图标与光标 | 电脑、文件夹、文档、钥匙、勾、叹号、红叉图标和像素光标（箭头、手形）从矢量素材 `AI矢量.ai` 裁剪导出，放在 `assets/img/ui/`；其余图标自绘 |
| 电脑壁纸 | 工作站桌面用 Windows XP 的 Bliss 壁纸（`assets/img/wallpaper-bliss.jpg`） |
| 素材授权风险 | 矢量素材看起来是图库素材，Bliss 版权在微软：只适合私下小范围分享，公开发布或上架 Steam 前必须确认授权或替换（见 `LICENSES.md`） |
| 玩家手机 | 手机里的内容之后由项目负责人另给，现在保持原样 |
| 字体 | 方舟像素字体（Ark Pixel Font，SIL OFL 1.1），登记在 `LICENSES.md` |
| 提示 | 不显示谜题提示按钮和提示文字；数据里的 `hints` 字段保留，暂不渲染。角色自己设的“密码提示”属于谜题内容，照常显示 |
| 设定改动 | 第一章便签位置由“显示器背面”改为“显示器侧面”（`docs/story.md` 已改；桌面上的 docx 原稿未改） |
| 场景图 | 每个地点一张 SVG，放 `assets/img/scenes/<scene>.svg`，进入该场景时才加载；可点的物件在 SVG 里用 `id="hs-…"` 标出，数据里用 `svgId` 对应；点击区域悬停时没有高亮，只有手形光标；`states` 里的图层在某个谜题解开后显示（如开门） |

## 数据怎么组织

```
data/
├── map.json                 楼层与地点，哪些地点一开始就开放
├── notebook.json            笔记本第一页（探险家手写）
├── locations/<id>.json      每个地点一个文件：描述、场景图、热点（资料、电脑、门禁）
├── computers/<id>.json      每台电脑一个文件：登录谜题、应用、条目
├── computers/shared/        多台电脑共用的应用（新闻、天气）
└── i18n/zh-CN.json          界面文字
```

- 文本里的 `[[词]]` 渲染成可点击的词，点击后收录进笔记本；`{{now}}` 显示游戏里的“现在”。
- 谜题解开后的效果写在 `onSolve`：`unlockPlace`、`login`、`flag`、`giveItem`。
- `npm run check` 校验数据：JSON 能解析、`[[ ]]` 配对、没有明文答案字段、场景里的 `svgId` 在 SVG 里真实存在。
